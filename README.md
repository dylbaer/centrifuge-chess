# Centrifuge Chess

A retro-arcade puzzle game about balancing centrifuge rotors. Ten centrifuges sit
along a lab bench. Each one is loaded with tubes and out of balance; you place the
tubes from your tray so the forces cancel, close the lid, and move to the next one.

## Run it

```bash
pip install -r requirements.txt
streamlit run app.py
```

Deploying: push this folder to GitHub, then point
[share.streamlit.io](https://share.streamlit.io) at `app.py`. No build step.

## The puzzle

A tube at rotor position *i* of *n* pulls outward along angle `2πi/n`. The rotor is
balanced when the mass-weighted vectors sum to zero. That means opposite pairs work,
but so do three tubes at 120° and four at 90° — and so do combinations of those.
Later levels mix 1.5 mL through 50 mL tubes and disable some buckets, so the obvious
pairing is often unavailable.

Levels are generated by assembling a known-balanced rotor out of regular polygons and
then lifting some tubes back out into your tray, so **every level is guaranteed
solvable**. Any balanced arrangement scores; you're not required to find the original.

### Scoring

| Component | Max | Notes |
|---|---|---|
| Accuracy | 600 | `600 × (1 − residual/tolerance)`. A perfect zero scores full marks. |
| Speed | 400 | Scales with how far under par time you finish. |
| Aborted spin | −75 each | Spinning while over tolerance trips the alarm and costs points. |

Tolerance is 2.5–5.5% of the loaded mass depending on level, so a slightly imperfect
load can still pass — for fewer points.

## Leaderboard

The app writes to Google Sheets when configured and falls back to a local
`leaderboard.json` otherwise. **On Streamlit Community Cloud the local file is wiped
every time the container restarts**, so use Sheets for a real global board.

1. Create a Google Sheet with a worksheet named `scores` and a header row:
   `name`, `score`, `levels`, `seconds`, `when`
2. In Google Cloud, create a service account, enable the Google Sheets API, and
   download its JSON key.
3. Share the sheet with the service account's email address, with edit access.
4. Add the credentials to `.streamlit/secrets.toml` locally, or paste them into
   **App settings → Secrets** on Streamlit Cloud:

```toml
[connections.gsheets]
spreadsheet = "https://docs.google.com/spreadsheets/d/YOUR_SHEET_ID/edit"
worksheet = "scores"
type = "service_account"
project_id = "your-project"
private_key_id = "..."
private_key = "-----BEGIN PRIVATE KEY-----\nYOUR\nKEY\n-----END PRIVATE KEY-----\n"
client_email = "centrifuge-chess@your-project.iam.gserviceaccount.com"
client_id = "..."
auth_uri = "https://accounts.google.com/o/oauth2/auth"
token_uri = "https://oauth2.googleapis.com/token"
auth_provider_x509_cert_url = "https://www.googleapis.com/oauth2/v1/certs"
client_x509_cert_url = "..."
```

The game shows which backend is live under the high-score table. Add
`leaderboard.json` to `.gitignore` so local play doesn't end up in commits.

## Adding levels

Append a `LevelSpec` to the `LEVELS` list in `app.py`:

```python
LevelSpec(
    name="ULTRA-48", subtitle="fixed-angle, half dead",
    slots=48, total_tubes=24, to_place=5, blocked=12,
    masses=(1.5, 2.0, 5.0, 15.0), tol_frac=0.025, par_seconds=120,
)
```

Constraints: `total_tubes + blocked ≤ slots`, and `total_tubes` must be expressible as
a sum of group sizes drawn from the divisors 2, 3 and 4 of `slots`. The bench cutscene
scrolls automatically, so no art changes are needed.
